# Images — drop real assets here

Every slot on the site loads a file from this folder and **falls back to a labeled
placeholder** if the file isn't present. Drop in files with these exact names and
they appear automatically — no code changes needed.

| Filename | Where it shows | Suggested size |
|----------|----------------|----------------|
| `logo.png` | Header + footer logo (and the maintenance guide) | ~200×60, transparent PNG or SVG* |
| `hero.jpg` | Full-width hero background | ~1600×900, landscape |
| `gallery-1.jpg` | Gallery — driveway | ~800×600 |
| `gallery-2.jpg` | Gallery — driveway | ~800×600 |
| `gallery-3.jpg` | Gallery — commercial lot | ~800×600 |
| `gallery-4.jpg` | Gallery — line painting | ~800×600 |
| `gallery-5.jpg` | Gallery — crew / equipment | ~800×600 |
| `gallery-6.jpg` | Gallery — finished edge | ~800×600 |

\* For an SVG logo, name it `logo.svg` and update the two `logo.png` references
in `index.html` (and one in `driveway-maintenance-guide.html`).

Good things to pull from the old site or your phone: the **company logo**, shots of
the **equipment/trucks**, and **finished driveways / lots**. JPG for photos, PNG/SVG
for the logo.
